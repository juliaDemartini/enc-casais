# Eu Vou! — Encontro de Casais

Site estático para personalizar um card vertical para Status/Stories.

## Como abrir
1. Abra esta pasta no VS Code.
2. Abra `index.html` no navegador. Para desenvolvimento, é recomendado instalar a extensão **Live Server** no VS Code e clicar em **Go Live**.
3. Escolha uma foto do casal e preencha os nomes/mensagem.
4. Clique em **Baixar meu card (PNG)**.

## Arquivos
- `index.html`: estrutura e formulário
- `style.css`: identidade visual vinho, dourado e creme
- `script.js`: prévia, download PNG e compartilhamento

## Observações
- O local está como “Em breve”, conforme informado.
- A foto é usada localmente pelo navegador; não há upload para servidor.
- A geração PNG depende de carregar a biblioteca html2canvas por CDN, então é necessária conexão com a internet para essa biblioteca e para as fontes externas.
- O compartilhamento direto de arquivos depende do navegador/dispositivo. Se não estiver disponível, o site baixa a imagem e abre o WhatsApp para você anexá-la.
- Substitua os textos/logotipo se a igreja desejar incluir a imagem oficial do brasão no card.
